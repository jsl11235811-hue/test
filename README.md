# 🐍 贪吃蛇游戏 (Snake Game)

一个经典的贪吃蛇网页游戏，使用纯 HTML、CSS 和 JavaScript 构建。

## 🎮 如何开始

### 在线游玩

1. 克隆或下载这个仓库
2. 直接在浏览器中打开 `index.html` 文件
3. 开始游戏！

### 本地运行

```bash
# 克隆仓库
git clone https://github.com/jsl11235811-hue/test.git
cd test

# 在浏览器中打开 index.html
# Windows: start index.html
# macOS: open index.html
# Linux: xdg-open index.html
```

或者直接双击 `index.html` 文件。

## 🎯 游戏特性

- ✨ 流畅的游戏体验
- 🎨 现代美观的界面设计
- 🎮 支持键盘控制（方向键 + WASD）
- 📊 实时分数显示
- 🏆 本地最高分记录
- ⚙️ 三种难度级别（简单/中等/困难）
- ⏸️ 暂停/继续功能
- 🔄 随时重置游戏
- 📱 响应式设计

## 🕹️ 游戏控制

### 键盘操作

- **方向键** `↑` `↓` `←` `→` - 控制蛇的移动方向
- **WASD 键** `W` `A` `S` `D` - 替代方向键控制
- **空格键** `Space` - 暂停/继续游戏

### 按钮操作

- **开始游戏** - 启动新游戏
- **暂停** - 暂停或继续当前游戏
- **重置** - 重置游戏到初始状态

## 📖 游戏规则

1. 🐍 控制蛇在游戏区域内移动
2. 🍎 吃到红色食物得 10 分，蛇身变长
3. 💥 撞到墙壁或自己的身体，游戏结束
4. 🏆 尽可能获得最高分！

## 🎚️ 难度设置

- **简单** - 蛇移动较慢，适合初学者
- **中等** - 标准速度，平衡的挑战
- **困难** - 蛇移动很快，高难度挑战

## 🛠️ 技术栈

- HTML5 Canvas - 游戏渲染
- CSS3 - 样式和动画
- Vanilla JavaScript - 游戏逻辑
